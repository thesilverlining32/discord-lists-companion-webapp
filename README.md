# My List App

* Mongo database
* Discord OAuth to create/login to account
* Mobile friendly design
* Users can Create/Edit/Delete Lists and List Items
* List Items can be Movie, Games, Books, Comics, or Custom.
* When adding Movies, Games, Books or Comics the software should allow the user to Search the appropriate open source database and add the item and its metadata, including picture and information. Custom items allow the user to input this information.
* Users can add/update ONE rating to any list item after it is created.
* Some basic User management - only approved people can see/edit/update lists.

A web application to manage lists of ideas, games, books, movies, and TV shows with Discord authentication.

## Setup

1. Clone the repository
2. Install dependencies for the backend and frontend:
	```bash
	cd backend
	npm install
	cd ../frontend
	npm install
	```
